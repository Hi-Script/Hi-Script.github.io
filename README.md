# HiScript 2.0 website starter

This is the first clean rebuild of the HiScript website.

## Before publishing

1. Copy the exact existing `logo.png` from the current HiScript repository into `assets/logo.png`.
2. Review all claims and replace placeholder project cards with verified work.
3. Confirm the event date, registration destination, social URLs, and contact workflow.
4. Test the Formspree endpoint before launch.
5. Enable HTTPS/GitHub Pages and test mobile layouts.

## Files

- `index.html` — homepage
- `solutions.html` — technology solutions
- `academy.html` — HiScript Academy
- `projects.html` — project showcase
- `events.html` — events
- `insights.html` — insights
- `about.html` — company positioning
- `contact.html` — contact form
- `css/styles.css` — shared design system
- `js/main.js` — lightweight navigation/form behavior

## Positioning

HiScript builds technology.
HiScript Academy builds people who build technology.

Learn. Build. Ship.


### Step 5 correction
The Events, homepage, and Academy messaging now position HiScript as bridging technology with **every discipline**. Biology, linguistics, biochemistry, and other fields are examples rather than the boundary of the mission.

## Step 6 — Insights / Knowledge Hub

This version builds on the corrected Step 5 Events package. The Insights page is now positioned as a knowledge hub for technology, learning, research and interdisciplinary work across every discipline. It includes editorial pillars, content formats, an awareness-campaign section and CTAs into the Academy and Events experiences.

## Step 8 — About / Brand Story

The About page is now the clearest statement of HiScript's identity: technology can connect with every discipline. It explains the two connected sides of the brand — building useful technology and building people who build — while making the Learn → Build → Ship model and interdisciplinary philosophy explicit.


### Step 9.1 — Contact email delivery
The contact form is configured to submit through FormSubmit to `contact.us@hiscript.com.ng`. On first use, FormSubmit will send a one-time activation/confirmation email to that inbox. The visitor's email is submitted as the `email` field so the received message can be replied to directly.
